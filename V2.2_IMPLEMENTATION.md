  .select('*', { count: 'exact', head: true })
  .gte('xp', 10);

supabase
  .from('memorizacao')
  .select('*', { count: 'exact', head: true })
  .eq('status', 'memorizado')
  .gte('updated_at', today);

supabase
  .from('memorizacao')
  .select('user_id')
  .eq('status', 'memorizado');

## ⚙️ Configuração Necessária

### 1. Ativar Tracking (Obrigatório)

Acesse **Lovable Cloud → Database → app_settings** e configure:

```sql
-- Habilitar tracking
UPDATE app_settings 
SET value = 'true' 
WHERE key = 'tracking_enabled';

-- Configurar IDs (obtenha nas plataformas)
UPDATE app_settings SET value = 'SEU_PIXEL_ID' WHERE key = 'meta_pixel_id';
UPDATE app_settings SET value = 'G-XXXXXXXXXX' WHERE key = 'google_analytics_id';
UPDATE app_settings SET value = 'SEU_PIXEL_CODE' WHERE key = 'tiktok_pixel_id';
UPDATE app_settings SET value = 'SEU_PARTNER_ID' WHERE key = 'linkedin_partner_id';
```
