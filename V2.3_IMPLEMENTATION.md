## 🗄️ Backend Implementado

### 1. Tabela: `content_types`
Gerencia os tipos de conteúdo disponíveis na plataforma.

**Colunas:**
- `id` (UUID) - Primary Key
- `nome` (TEXT) - Nome do tipo (ex: "Rituais")
- `slug` (TEXT, UNIQUE) - URL-friendly (ex: "rituais")
- `descricao` (TEXT) - Descrição do tipo
- `icon` (TEXT) - Nome do ícone Lucide (ex: "Flame")
- `ordem` (INTEGER) - Ordem de exibição
- `ativo` (BOOLEAN) - Se está ativo

**Dados iniciais:**
1. Odu Ifá (slug: `odu`) - 📖 BookOpen
2. Rituais (slug: `rituais`) - 🔥 Flame
3. Rezas (slug: `rezas`) - ❤️ Heart
4. Invocações (slug: `invocacoes`) - ✨ Sparkles

**RLS:**
- ✅ SELECT: Qualquer pessoa
- ✅ ALL: Admins e Colaboradores

---

### 2. Tabela: `ritual_content`
Armazena todo conteúdo além dos Odu (rituais, rezas, invocações).

**Colunas:**
- `id` (UUID) - Primary Key
- `content_type_id` (UUID) - FK para content_types
- `numero` (INTEGER) - Número sequencial (opcional)
- `nome` (TEXT) - Nome do ritual/reza
- `texto_principal` (TEXT) - Conteúdo principal
- `materiais_necessarios` (TEXT[]) - Array de materiais
- `tempo_execucao` (INTEGER) - Minutos estimados
- `dificuldade` (TEXT) - 'iniciante', 'intermediario', 'avancado'
- `odu_relacionados` (UUID[]) - Array de IDs de Odu
- `tags` (TEXT[]) - Tags para busca
- `verso_resumido` (TEXT) - Resumo do verso
- `contexto_historico` (TEXT) - Contexto histórico
- `exemplos_praticos` (TEXT) - Exemplos práticos
- `audio_url` (TEXT) - URL do áudio (para rezas)
- `created_at`, `updated_at` (TIMESTAMP)

**Conteúdo inicial:**
- 1 ritual de exemplo: "Ritual de Abertura de Caminhos" (Exu)

**RLS:**
- ✅ SELECT: Qualquer pessoa
- ✅ INSERT/UPDATE/DELETE: Admins e Colaboradores

**Indexes:**
- content_type_id
- dificuldade
- Tags (para busca)

---

### 3. Tabela: `user_ritual_progress`
Rastreia progresso individual em rituais/rezas/invocações.

**Colunas:**
- `id` (UUID) - Primary Key
- `user_id` (UUID) - FK para profiles
- `ritual_id` (UUID) - FK para ritual_content
- `status` (TEXT) - 'nao_estudado', 'estudando', 'praticado'
- `vezes_praticado` (INTEGER) - Contador de práticas
- `ultima_pratica` (TIMESTAMP) - Data da última prática
- `proxima_revisao` (TIMESTAMP) - Próxima revisão sugerida
- `notas_pessoais` (TEXT) - Notas do usuário
- `created_at`, `updated_at` (TIMESTAMP)
- UNIQUE(user_id, ritual_id)

**RLS:**
- ✅ SELECT/INSERT/UPDATE/DELETE: Apenas próprio usuário

**Indexes:**
- user_id
- ritual_id
- status

**Queries implementadas:**
```typescript
// Carregar tipos de conteúdo
supabase.from('content_types').select('*').eq('ativo', true).order('ordem');

// Carregar rituais de um tipo
supabase.from('ritual_content').select('*').eq('content_type_id', typeId).order('numero');

// Carregar progresso do usuário
supabase.from('user_ritual_progress').select('*').eq('user_id', userId);
```

```typescript
supabase.from('ritual_content').select('*').eq('id', ritualId).single();

// Carregar progresso
supabase.from('user_ritual_progress').select('*').eq('user_id', userId).eq('ritual_id', ritualId).single();

// Carregar Odu relacionados
supabase.from('odu').select('id, numero, nome').in('id', oduIds);

// Marcar como praticado
supabase.from('user_ritual_progress').upsert({
  user_id, ritual_id, status: 'praticado', 
  vezes_praticado: count + 1, ultima_pratica: now()
});
```
